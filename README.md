# ScalerNews Theme

A highly customizable, fast, and elegant WordPress theme designed for news, blogs, and publishing websites.

## Features

* **Advanced Customization**: Granular control over typography, colors, and layouts.
* **Component-Based Styling**: Dedicated files for individual UI components to keep styles organized.
* **Optimized Performance**: Clean codebase and modular design for fast loading times.
* **Responsive Layouts**: Designed to look clean and beautiful on all devices.
* **Modern Aesthetic**: Focus on readability and presentation.

## Installation

1. Download or clone this repository to your local machine.
2. Upload the `ScalerNews` folder to the `/wp-content/themes/` directory on your WordPress installation.
3. Activate the theme from the Appearance > Themes dashboard in WordPress.
4. Go to Appearance > Customize to adjust the theme settings to your preference.

## Structure

* `/assets`: Contains compiled CSS, JavaScript, and other static assets.
* `/inc`: Contains theme functions, template tags, customizer logic, and patterns.
* `/template-parts`: Contains partial template files like content blocks, headers, single post layouts, etc.

## Development Setup

If you wish to modify the theme, you can utilize the included style, block, and editor CSS files. JavaScript logic handles navigation and customization previews.
